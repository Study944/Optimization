# 2026/5/9 修改为池化，邻居有效性权重+池化
**版本2.1.1：**
- 超参数：k值
- 数据集：iris 和 wine 和 breast-cancer
- 权重配置：无特征权重，有样本权重（邻居有效性权重+池化）
- 结果：实验结果不可观甚至更低了，池化可能导致其他问题，邻居有效性权重+池化可能惩罚过重且忽略了类别邻居数量的问题

# 2026/5/10 添加特征权重作为超参数
**版本3.1.0：**
- 超参数：k值，特征权重
- 数据集：iris 和 wine 和 breast-cancer 和 adult
- 权重配置：有特征权重（每个特征都有一个权重系数，区间[0,1]），无样本权重
- 结果：实验结果可观，对数据集中的一些相关性低的样本进行减低权重操作
- 后续改进点：当前使用的适应度函数依旧是准确率，为了避免过拟合后续考虑修改如F1值或者召回率再如添加惩罚系数
